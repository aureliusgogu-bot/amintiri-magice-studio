# #facemceneplace

Site de prezentare (portofoliu foto & video) pentru **#facemceneplace**. O singură pagină, în limba română.

- Galerie 3D cu parallax, înclinare la mouse și previzualizare pe tot ecranul
- Secțiunea „Povestea noastră" și formular de contact (se deschide aplicația de e-mail, fără backend)
- Contact: facemceneplace@gmail.com

## Înlocuirea fotografiilor

Fotografiile din galerie sunt demonstrative. Lista lor se află la începutul fișierului `src/components/portfolio-gallery.tsx` (sursă, raport, categorie, titlu). Imaginile din secțiunile „Povestea noastră" și „Contact" sunt definite în `src/routes/index.tsx`.

## Dezvoltare

```bash
bun install
bun run dev
```
